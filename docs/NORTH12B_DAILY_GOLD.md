# 北一二B 每日接龍金牌

北一二B 日結與北一二部公司月度 Final 是獨立資料。日結來源為對話中已確認的結算總表，結算日期須由原始內容或 Liam 明確確認。不得用訊息發送日推定結算日期，不得把代稱當成公司員編。

## 私有資料與直接更新

正式檔名 `north12b-gold-daily-private-latest.json`，放在既有 `SPREADSHEET_ID` 所屬私有父資料夾。資料、員工牌數與 Drive 檔案 ID 不得提交公開 repo。契約 `north12b-daily-gold/v1` 由 `gold-daily-core.js` 驗證。

每次確認結算後：

1. 讀取目前正式檔，確認其父資料夾及私有權限；保留既有日結與 `personKey`。
2. 只寫入已確認的日期、九店代稱及總牌數。代稱或店點變更需確認身分，不得自動建立員編對照。第一筆無前日基準，增減為空。
3. 新日期追加一筆；同日修正先保存私有備份再替換該日，不能累加同日總牌數。未知原因與免扣保留空白。
4. 驗證日期不重複、人員不重複、牌數為整數及逐店人數。以 Drive 原檔 ID 更新，不建立多個同名正式檔。
5. 讀回比對全部值及私有權限，使用免登入查詢頁或督導工作階段檢查正式頁面後回報。

不同日结是餘額快照，不能相加當作期間累計。僅連續兩日、同一 `personKey` 均有資料時呈現差額；缺日或新人顯示無前日基準。總牌數確認不表示未知增減原因已完成複核。

## 部署相依

主 GAS 新增 `GoldDailyCore.gs`、`GoldDaily.gs`，`department_gold_access` 提供免登入、唯讀的已確認日結，僅回傳契約驗證過的接龍代稱與牌數，不讀取員編／裝置名冊。

巡店 GAS 同樣新增兩個檔案；`north12b_gold_read` 仍先通過原督導工作階段驗證。執行 `node scripts/build-patrol-gas-bundle.mjs` 產生 bundle。

先取得並比對線上最新 GAS，最小修改現行 `Code.gs` 的日結讀取與路由，保留秘密、權限與所有既有功能。兩個 Web App 都需更新既有部署的版本，不能只按存檔，也不能替換 URL 或新增公開權限。依受影響後端更新既有 Web App 版本後才發布前端。門市查詢頁免登入；督導讀取與所有維護、發布動作仍維持原驗證。驗證匿名可讀已確認日結，以及督導未登入請求仍被拒絕。回復點為部署前版本及前端上一個 commit。

## 公開查詢白名單

`department_gold_access` 使用 `north12b-public-gold/v1`，僅傳回結算日期及每人店點、接龍代稱、餘額、每日數值增減。跨日差額在後端按私有人員鍵計算；不傳人員鍵、來源、記錄時間、原因、免扣或出勤／休假資訊。督導驗證後仍讀取完整私有 ledger，正式檔案不變。
