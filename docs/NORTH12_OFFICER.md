# 北一二部長官版：締結率、來客與改善建議

依 Liam 2026-10-29 最新指示，長官版不放 KPI／台獎。`north12-officer.html` 只呈現 AQ／RT 締結率、來客數、上月同期 MoM、每週人次、每日趨勢與改善建議。

只在本機解析 AQ締結率、RT每日、RT締結率，樞紐為同期核對選用來源；另讀取 Tier觀察、RT用戶進店行為_店、未續約明細以產生區店彙總。不解析個績、不上傳原檔、不改 B 區私有後端與權限、不使用持久資料快取。客戶識別僅在本機解析未續約明細時用於去重，匯出僅含白名單彙總。可多檔加入同截止來源，或取一份含四區的原報。門市名冊從 AQ 建立，RT 兩張表逐店交叉核對；缺店、缺日、計數異常、期間不同與不支援的月版型拒絕。按來源月份的實際天數與欄位標題核對日期、每日率、TTL 與同期文字；欄位驗證與 B 區共用，分子母合計、每日與週彙總重用既有唯讀核心。

新增差異只為部區範圍：名冊允許 A／B／C／D；RT總表在分子、分母明確都是數值0時可接受空白率，輸出依舊為 null／—，不把缺少計數當零。AQ精確文字0相容規則保留原限制，不接受任意文字、公式快取或空白計數。

區／店可篩選日期與三個頁籤；同期原報只有整段總量，部分日期不顯示不相配的 MoM。部整體與區締結率都由分子母合計重算，不平均百分比。AQ／RT來客不相加為門市總人流。改善建議以觀測差異提出檢查方向，不宣稱已確認原因；Tier與方案未核對，不編造。

現有實際來源 `202610_AQ、RT 締結率報表1014.xlsx` 含四區37店（A9／B9／C9／D10），截止10/13、前期9/1–13，共481店日。這是來源截止，並非網站更新日。來源位於既有私有檔案，真資料與匯出HTML不得放 repo／公開 Pages。

「匯出長官唯讀版」只保留區店彙總白名單，HTML無登入、原報明細、憑證與網路依賴。更新資產執行 `node scripts/build-north12-officer.mjs`；驗證 `node --test tests/north12-officer.test.cjs`。四區實際來源已核對數量、日期與TTL，與單區既有解析器有B區相同值回歸，瀏覽器另檢查篩選與三頁呈現。


## 格式相容與分項檢查（2026-11-13）

- 接受 XLSX／XLSM（不執行 VBA）。工作表名稱可有空白、全半形與不可見字元差異，但不把統計口徑不同的相似名稱視為同一張表。例如「RT用戶進店行為」不等於「RT用戶進店行為_店」。正規化後同名的多張來源拒絕自動選取。
- 依已知欄位群尋找表頭，接受前置說明、空白列與整張表格向右位移。核心三表仍須核對逐日日期、店碼、區域、分子母及 TTL；不將空白計數補零、不猜未知欄位。未續約明細依欄名對應，重複必要欄名拒絕。
- Tier觀察混有區級及 DNB 店級列時，區級彙總只取區級列。相同重複彙總去重；同一鍵數值衝突不採用。三張續約分析分別檢查，失敗項清空並顯示具體原因，有效的其他項及核心資料仍可匯出。錯誤資訊保留在離線版；缺表不顯示成零。
- 缺樞紐時僅顯示當期，不顯示未核對的 MoM。RT每日缺百分比區塊時，從 TWM／TST 分子母重算並核對總表。
- 每批檔案先完成核對，再一次替換畫面；核心失敗保留原資料並列出每個失敗檔案。不同截止日的新批次替換舊期間，同批次仍必須同期間。清除或再次選檔後，舊的非同步讀檔不得回填畫面。相同期間全區重新上傳，可恢復先前未通過檢查的分析項目。
- 回歸包含三張分析的有效／缺少／錯誤共 27 種組合、版面及工作表名稱變體、重複資料、期間更新、讀取途中清除、篩選及離線匯出。正式原檔只在私有工作區驗收，不加入 repo。
