# 北一二部長官唯讀看板

`north12-officer.html` 是可本機匯入每日戰報的獨立介面，不取得既有 B 區私有 API 的其他區權限。只讀 `上線數KPI_店點達成率_明細`，不解析個績／門號／客戶表，也不上傳原檔或寫入瀏覽器持久儲存。

A／B／C／D 同期檔可多選或分次加入；期間不一致拒絕整批，相同區新檔替代原區，不累加。依實際來源顯示已提供區、缺少區及門市；缺區不計部整體，也不以 B 區冒充全部。區整體、公司排名及進度率沿用原報，不平均各店或各區百分比。KPI 明細及選單列原報有權重項目；管理重點只是低進度項目的待查提醒，不宣稱已確認原因。

「匯出長官唯讀版」產生不需登入、可離線篩選的 HTML。白名單只保留區店彙總，沒有憑證、個人資料或後端入口；匯出檔本身包含公司業績，依使用者指示交付與保管，不放公開 repo 或 Pages。介面與匯出是同一份來源，更新資產執行 `node scripts/build-north12-officer.mjs`。

目前已核對的 `1029.xlsx` 僅北一二B／九店，來源截止 2026-10-28。這不能代表全北一二部已備齊。台獎、個績、Tier、方案、締結率及來客四區來源未串接，本版不呈現代替值。

驗證：`node --test tests/north12-officer.test.cjs`；與真實原報核對區值、排名、九店及期間，並檢查離線篩選與缺區提示。線上頁只含空介面與程式，真資料輸出需留在 repo 外。
