# 北一二部長官版：締結率、來客與改善建議

依 Liam 2026-10-29 最新指示，長官版不放 KPI／台獎。`north12-officer.html` 只呈現 AQ／RT 締結率、來客數、上月同期 MoM、每週人次、每日趨勢與改善建議。

只在本機解析 AQ締結率、RT每日、RT締結率、樞紐四張彙總表；不解析個績或客戶明細、不上傳原檔、不改 B 區私有後端與權限、不使用持久資料快取。可多檔加入同截止來源，或取一份含四區的原報。門市名冊從 AQ 建立，RT 兩張表逐店交叉核對；缺店、缺日、計數異常、期間不同與不支援的月版型拒絕。原 31 天表格的欄位語意／每日率／TTL／同期文字守門沿用 B 區已核對邏輯，分子母合計、每日與週彙總重用既有唯讀核心。

新增差異只為部區範圍：名冊允許 A／B／C／D；RT總表在分子、分母明確都是數值0時可接受空白率，輸出依舊為 null／—，不把缺少計數當零。AQ精確文字0相容規則保留原限制，不接受任意文字、公式快取或空白計數。

區／店可篩選日期與三個頁籤；同期原報只有整段總量，部分日期不顯示不相配的 MoM。部整體與區締結率都由分子母合計重算，不平均百分比。AQ／RT來客不相加為門市總人流。改善建議以觀測差異提出檢查方向，不宣稱已確認原因；Tier與方案未核對，不編造。

現有實際來源 `202610_AQ、RT 締結率報表1014.xlsx` 含四區37店（A9／B9／C9／D10），截止10/13、前期9/1–13，共481店日。這是來源截止，並非網站更新日。來源位於既有私有檔案，真資料與匯出HTML不得放 repo／公開 Pages。
