# 未過關回填文字提示（2026-10-21 起）

以台灣回報日期判斷，自 2026-10-21 起，僅針對每日未過關 −3 的免扣資格。2026-10-20（含）以前不追套，不追改已結算歷史；其他動員、動店、保險、值班 −5 或 SPE 不適用。

當日 seg16、seg21 都須有完整個人回報。每段 `extra.fail_reason`、`extra.consult_store`、`extra.consult_person`、`extra.consult_method`、`extra.improve_plan` 完整，且後兩欄各至少 50 字。去除 Unicode 空白與標點後，按 Unicode code point 計數；不排除 emoji、不限定中文字，也不另作 grapheme 合併或正規化。請寫具體做法與改善行動，勿含客戶個資。

前端 `personalFailTextCheck` 只提示單段字數與缺欄，並非正式每日資格引擎。即使本機兩段都有紀錄，也不確認整日免扣。每日須讀回兩時段原始個人回報，把完整內容提供督導覆核，督導可判定扣回。店長／指定代理既有免個人回報例外保留；不等於自動免未過關 −3，爭議由督導覆核。

正常保存與免扣資格分開：原因與改善原有非空檢查不變；不足 50 字、請益缺欄仍可保存並提示未達免扣文字條件。接客數／上線項目未新增必填。全部過關仍直接保存 `extra={}`。既有資料 keys、雲端傳輸與後端未更改。

未過關保存訊息明確區分「已儲存於本機」及「雲端結果尚待確認」；此更新未新增雲端讀回、每日結算或每日報表傳送流程。正式雲端保存與督導每日完整內容核對仍須依現有原始回報執行，不能以此 UI、本機紀錄或 CI 代替。
