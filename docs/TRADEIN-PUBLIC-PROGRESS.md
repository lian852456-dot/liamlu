# 舊換新公開目標進度候選

使用者核定免登入查看區、店及個人上線數與目標進度，姓名中間隱碼。手機專案查價、回收價、原私人讀取與管理者更新權限仍各自使用既有流程。

`tradein-public/v1` 公開讀取使用 POST，僅接受月份，回應只有 `snapshot` 與 `availableMonths`。快照包含月份、來源期間／截止、發布時間、區彙總、九店彙總與人員公開列。各列只包含隨機公開 ID、店點、隱碼姓名、實績、目標、尚缺及進度，不包含職務、員編、來源對照、交易或 Drive 指標。後端建立新物件與重新隱碼，並核對每一層完整鍵集合；前端再驗證同一格式。

同名隱碼人員保持不同列及不同隨機 ID，不以姓名或店點合併。ID 不從員編或其雜湊產生；相同私人版本的重複公開操作不改 ID。台數按原每月 3 台規則，免目標人員的目標與尚缺為 null。未知月份清空舊數字與匯出。

私有資料夾內另存公開投影檔與公開月索引，原資料夾的分享權限不變。索引須對應目前私人 active 版本及核定月名冊；任何版本或基線漂移、損毀、格式錯誤皆停止讀取。匿名路由不呼叫私人 reader、裝置驗證或 auth state 初始化。

更新與檢查點只接受既有 `reportUploadAuthorize_`。檢查點與公開發布另要求非秘密 `TRADEIN_PERFORMANCE_OWNER_SCRIPT_ID` 與目前 Script ID 完全相同，不依賴或啟用全域 auth gate。前端管理者密碼只暫存於操作記憶體，不存入瀏覽器 storage；匿名請求不帶員編、裝置或密碼。

更新順序是預覽 → C1 檢查點 → 私人月版本保存／回讀 → 公開投影保存／回讀。C0 可在首次配置前保存空月狀態；C1 核對本批來源、月名冊及預覽。回復須通過現在私有／公開索引、active 與兩份配置的完整 CAS，僅恢復指定月份與檢查點中的既存配置。首次空月回復清除該月指標，保留歷史檔；其他月份保留。操作非跨檔案原子交易，部分保存失敗時須重新核對狀態後回復，讀取依版本一致性 fail closed。

目前是本機候選。GAS 原始碼存檔、建立版本、Web App 部署與正式資料回讀必須分別驗證，不能用本機測試或 HTTP 200 取代正式驗收。
