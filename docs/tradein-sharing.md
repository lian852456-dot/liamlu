### 公開範圍與原權限

- 只有新案例在填寫時勾選明示公開同意，才由伺服器寫入 `audience: public-link/v1`。私有月檔仍沿用 v1 schema；缺少旗標或其他值一律私有。舊案例不能藉編輯升級公開，不搬移或公開舊圖片。
- 新分享自行選店點、填姓名；姓名明示「自填未驗證」，不解析成員編或登入身分。匿名新增的 `owner` 為 null，公開結果一律不可編輯；不發匿名編輯憑證，也不設共同匿名 actor。登入新增使用原 B session 綁定真正提交者，顯示姓名仍是自填，兩者不混用。
- 原作者登入編輯、督導編輯／隱藏／恢復／優良案例，繼續由既有 B 驗證、裝置、現職資格與鎖保護。新公開案例也可由督導管理。其餘員工、KPI、名冊、管理及裝置 API 不擴權。
- 公開 list、detail（含圖片）與提交結果讀回皆在伺服器檢查 `audience === public-link/v1 && hidden === false`，猜 ID 不能讀私有／隱藏內容。list 不含圖片本體，detail 僅回受檢查的 raster data URL；不公開 Drive URL、檔案或資料夾。
- 表單提醒勿填客戶個資、證件或訂單截圖；不宣稱自動去識別。仍有三種案例、原字數限制、一張 PNG/JPEG/WebP、800 KB 上限及簽名檢查。

### 日期與容量

- 分享自己的「每日／彙整區間」控制項，不監聽或修改進度月份、回收日期、區／店／個人篩選或回收價功能。
- 每日依首次 `createdAt` 的 Asia/Taipei 日期；公開新增的儲存月份由伺服器選定，編輯保留首次建立時間。舊私有案例保留原儲存月份供原權限讀取／編輯，不做歷史搬移；登入後可明確選擇「原月份檢視」，一次只讀所選月，避免舊案例的儲存月與首次建立日不同而失去入口。
- 彙整預設台灣當月起訖；伺服器最長 93 個日曆日，最多讀四個月檔、最多回 500 案例；超量需縮小區間，不默默載入所有歷史。保留單月 500 則、序列化 8,000,000 字元上限。
- 所有公開操作也經原 owner ScriptLock；使用同私有資料夾內獨立 `north12b-tradein-sharing-public-guard.json` 保存全站限額：每分鐘 120 次、每小時新增 20 則、台灣每日 100 則、每店每日 20 則。讀取會更新非內容的限額檔。GAS 沒有可靠匿名 IP 證明，這些是全站容量保護，不能宣稱能杜絕惡意耗盡限額。

## 資料與權限

- 作者與門市由 B owner 已驗證的現職名冊取得，不接受前端指定作者。列表只回傳隱碼姓名與可編輯旗標，不回傳員編、裝置或 session。
- 同仁可看案例並編輯自己的內容。只有既有 primary trusted 員編且正式角色為「督導」，才能編輯他人、隱藏／恢復及標記優良案例。密碼通道的裝置豁免不代表管理權限。
- 月份與進度頁月份連動。案例類型為成功成交、未成交、改善心得，情境／話術／心得必填。依更新時間由新到舊，提供門市、同仁及類型篩選。
- 使用既有私有資料夾，檔名 `north12b-tradein-sharing-YYYY-MM.json`；不更改資料夾分享設定，不使用公開 JSON 或 localStorage 儲存案例。每月最多 500 則，單月序列化上限 8,000,000 字元。
- 選填一張 PNG／JPEG／WebP，最多 800 KB；圖片只在按「查看圖片」後透過已驗證 session 讀取，不建立公開圖片網址。圖片隨案例存在私有檔案；版本檢查避免舊編輯覆寫。
- 所有寫入在既有 B owner session transaction／lock 內執行，不自動重送。新增使用穩定 UUID；連線結果不確定時先重新讀取，同 ID／舊版本再次提交會遭拒。
- 隱藏、登出、月份變更與登入到期會清除畫面內私有資料；每次回覆採用前重新核對原 session 與月份。
