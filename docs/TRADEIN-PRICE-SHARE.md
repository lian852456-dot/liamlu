# 跨區舊機回收價查詢（待分享授權與正式部署驗收）

## 用途與權限
- 新增 `tradein-price-share.html`，供其他區同仁用單一網址免登入查詢舊機回收價；無連回北一二B首頁、區／店／個人進度、簡報或管理入口。
- **原管理者的本機上傳完整保留**：督導從原「資料快速上傳」開啟正式 GAS 上傳頁，維持現有管理者驗證、選擇本機 Excel、解析／差異預覽、二次確認、正式 active 更新、讀回及回復流程。新頁不新增、修改或繞過上傳身分驗證。
- 同一套價格來源，不匯出原始 Excel、不同步第二份持久化快照。主管發布後，新查詢頁每次重新開啟或按「重新讀取報價」向正式 active 讀取。
- 前端僅使用既有白名單 `threec_snapshot_read`，固定 `kind:tradein`、`includeChanges:false`。不請求手機專案／3C 價格、價格異動細節或任何私有員工資料；不發出任何寫入呼叫。不儲存到 localStorage/sessionStorage。
- 回收商價格與 S/A/B/C（及來源未分級）只呈現實際有報價的值，0 元與缺價嚴格區別。讀取失敗、來源欄位不符、尚未發布時清空資料，不顯示過期價格。

## 分享授權與發布閘門
**本次僅製作候選與驗證，不合併 main、不觸發正式 Pages 發布，也不提供未經核准的對外分享網址。**

A 方案屬於「持有連結的任何人都可存取」，不是「只限台灣大哥大員工」。正式上線需由業務／資訊／資料權責單位確認回收商報價與供應商條件允許放在免登入可公開讀取的網頁；若不允許，需改為公司身分驗證方案 B，不能只靠隱藏頁面連結、robots noindex 或難猜網址保護資料。

部署前依序驗收：
1. 主管／公司授權確認：正式回收價、回收商價差與來源日期可否公開網頁供任何持有網址者查詢，確認是否需增加版權／價格有效期聲明。
2. PR CI：read-only 契約與 Playwright 模擬後端的電腦、390/320px 篩選、報價零值／缺價、錯誤清空、XSS、防跳回管理入口檢查。
3. 合併前由具權限者確認 main 原資料快速上傳入口及版本回復仍正常；不更動 GAS 部署、Secret、Registry 與管理角色白名單。
4. 經授權後合併並確認 GitHub Pages 發布完成，線上查詢頁實際從既有 GAS 讀回正式日期、機款及各家報價；重新整理結果一致，斷線可正常顯示錯誤。
5. 以公司電腦及同仁手機實際測試選機款、篩選與開啟分享連結。主管在原上傳頁完成一筆核准的更新演練，查詢頁刷新讀到新 active；再核對未更動管理授權及原績效頁。

### 回復
僅撤回或還原新頁面前端相關 commit/PR；不動私有快照、管理者上傳、正式 GAS Deployment。新頁與原價格模組共用只讀程式，但不更動原模組。
