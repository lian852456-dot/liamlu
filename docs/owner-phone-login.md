# App 手機自動登入

App 的主帳號可以首次驗證後綁定一個瀏覽器／PWA 裝置；後續以裝置憑證換發既有 30 分鐘 B session，不儲存密碼。只有既有 `DASHBOARD_TRUSTED_EMPLOYEE_ID` 主帳號可綁定；其他督導與同仁不適用。這是瀏覽器保存的憑證，不是硬體裝置認證。

手機設定：在已安裝的 App 按「首次驗證並綁定這支手機」，或登入後按「綁定這支手機，之後免輸帳密」。成功後顯示「手機自動登入已啟用」。不要在桌機執行手機綁定。

裝置憑證保留 90 天，每次成功自動登入續期。後端只保存雜湊，且每次登入仍核對現職、原生撤銷狀態、密碼版本與正式名冊授權。第二裝置不能取代仍有效的綁定。正式資料仍由原有資料層讀取。

登出會清除本機憑證並撤銷該手機的短效連線；管理區「解除手機自動登入」可遠端撤銷。換機、清除網站資料或長期未使用時需重新設定；遺失本機憑證時，先由管理區解除舊手機再綁定。停權、撤銷與密碼變更會阻止後續登入。網路失敗而未確認伺服器撤銷時，畫面會明確提示需從管理區處理。

本功能只處理 App 的 KPI／台獎／個績 B 登入。班表／巡店的獨立督導通行碼及其後端不變。

驗證：`owner-phone-backend.test.cjs`、`owner-phone-client.test.cjs`、`owner-phone-ui.spec.js`，並回歸既有 shared session、名冊續期、密碼管理與 Patrol 認證契約。真實 iPhone 首次綁定及關閉重開仍需使用者完成，不以合成瀏覽器代替實機驗收。

GAS 發布須從目前部署來源取回原檔，只覆蓋 B store/endpoint 區段並加入兩個 phone 常數，保留正式 release gates 與其他檔案。先保存來源及部署版本，正式 immutable 與 Web App 讀回通過後再發布前端。回復程式碼時不要還原舊密碼 verifier／epoch、名冊或撤銷資料；需要取消已發出的手機憑證時，先於管理區撤銷。
