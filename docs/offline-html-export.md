# HTML 離線匯出

所有報表匯出共用 `offline-html.js` 的 `north12-single-html/v1` 封裝：一般 UTF-8 `.html`、無 BOM、HTML5 doctype、`zh-Hant`、內嵌 CSS／一般 script／必要資料。下載 MIME 維持 `text/html;charset=utf-8`，不以壓縮檔、整檔 Base64、ES module 或 CDN 取代 HTML。

`finalize` 只整理 head，不改寫報表本文、公式、數值或來源。共用 CSP 保留禁止連線、表單、框架及外掛；樣式、互動碼與圖片限內嵌。參考報價檔沒有 CSP，不能把移除既有保護當成相容性修正，也不代表已通過公司未公開的資安政策。

| 入口 | 匯出內容與資料邊界 |
| --- | --- |
| KPI／台獎戰情（含每日回報內共用 controller） | 新增真正的 HTML 離線快照。只讀已通過原登入的 controller 記憶體，重新投影顯示欄位；包含已授權的各店、個人指標或全部台獎機款。缺值不補零，不序列化原始回應、profile、token、裝置碼或秘密。 |

| 部區店務／金牌 | 沿用已保存來源、月份、版本與欄位投影，詳見 `department-readonly-html.md`。 |
| 締結率／來客數／續約洞察 | 沿用已核對原報與既有彙總，重新執行 `node scripts/build-north12-officer.mjs` 更新內嵌元件。 |
| 督導巡店 | 沿用原工作階段、範圍、照片讀取及版本再核對。照片已內嵌，影片等附件仍是原私有連結，使用時需網路與權限。 |

所有下載檔都是匯出當下的資料；持有人能查看，不能當成可撤銷的登入連結，也不會自動取得後續正式更新。

## 舊換新提醒

`tradein-reminder.mjs` 產生精簡文字及 HTML，複製、PNG 預覽與 PNG 下載使用同一摘要。依目前範圍的已知回收台數排序，列店／個人 TOP3 與 BOT3；同台數並列並提示邊界同值數量，已列 TOP 不重複列 BOT。零台仍參與，未知不當零；人數不足時只列實際可用筆數。全體同值明示並列，不虛構優劣。

店點排名直接使用已驗證的店點彙總，保留跨店支援的原成交店歸屬，不從個人歸屬重加店台數。筆數篩選造成的人員子集合沒有完整店彙總時，店點排名顯示待核。單日及每月口徑分開；未知月份／日期、撤銷或清除資料仍停止下載。

回收機款只作本範圍優先核價提示。現有績效來源沒有實際檢測等級與同條件有效報價，故「價格優勢待核」；不能把兩家同字母分級當成相同狀況，也不能以參考最高價宣稱每台舊機可獲得該價。取得可比、有效且已核實的來源後再擴充。

## 驗證

`node --test tests/unified-html-export.test.cjs` 檢查格式、欄位投影、完整明細、排名、範圍與未知值。

`npx playwright test tests/unified-html-export.spec.js --workers=1` 使用合成資料驗證七種 HTML 的桌機／手機離線互動、實際下載、無外部資源、無憑證，以及登出／月份切換後阻擋。現場公司環境及實機 Safari 另行驗收，不以模擬寬度替代。
