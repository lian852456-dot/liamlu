# 管理辦法

`home.html` 督導區的管理辦法卡片位於 Liam 情報站旁。`management-policy.html` 使用既有 `tradein-supervisor-auth.mjs` 的 Patrol 督導驗證；沒有新增身分來源、正式資料讀寫或發布端點。

目前功能為本機編輯、JSON 草稿載入／下載、章節增刪、沙箱預覽及獨立門市唯讀 HTML。月份與起訖日期須一致；載入、編輯後重新確認核對與分享範圍。未核對內容始終標成待核草稿。草稿只在記憶體，背景、離頁、登出或驗證失效時清除；需要保留時先下載 JSON。

匯出只使用 `management-policy-core.mjs` 的明列欄位，不序列化應用程式、登入物件、Storage、名冊、任意 JSON 屬性或 Excel。所有文字先跳脫，預覽 iframe 僅允許固定月份篩選程式，保留不允許同源、表單及導覽的沙箱限制；獨立 HTML 以 CSP 禁止網路，腳本只放行固定程式的 SHA-256。基本偵測會阻擋常見憑證、員編標籤及聯絡資訊；這不是完整個資偵測，提供門市前仍須人工核對內容與對象。下載檔不另加開檔密碼。

正式辦法、實績、來源原圖及含私有資料的示例不進公開 repo。十月 Final 已由使用者確認並依 11/5 更正，檔案保存於私人 Library；驗證後頁面提供原有檔案權限保護的下載入口，不更改分享權限。JSON 下載後可由本機載入編輯，載入時仍會重設核對勾選。十一月辦法未提供，不當成十一月規則。

門市 HTML 提供月份篩選。單月輸出保留當月內容；`renderPolicyCollectionHTML` 可將已核對來源整理為多月份輸出，同月重複版本會拒絕。選到未提供月份時所有內容隱藏並明示缺資料，不回退其他月份。篩選是顯示控制，不是權限切分；每份檔案內全部月份均須符合提供對象的授權範圍。

## 每週 Excel：待接線的更新機制

介面目前只顯示「尚未啟用」。已有的對話週報產製不等於網站保存或更新，本次未建立或變更排程。

建議沿用既有私有 Drive 與已核准執行身分：產製後先保存不可變 Excel 版本，確認檔案位元組、SHA-256、統計月份、週別、資料截止日、辦法版本、來源與缺項，再原子更新目前版本索引。以月份、週別、真實截止日與內容 hash 作去重鍵；更新失敗保留上一個版本並明示日期，不冒稱已更新。通知只在保存與讀回核對完成後寄回既定本人對話，並對同版本去重。

需新增並獨立驗證受保護的清單與下載處理器：每次請求核對現有有效督導 session；伺服器核對允許的檔案 ID 與讀取範圍後回傳檔案。不要公開 Drive 分享連結、不把存取權杖放在網址，也不依賴瀏覽器篩選來限制個人資料。若未來開放門市，必須在伺服器依核准角色及門市裁切內容；目前不假設門市可讀完整個人明細。

接線前還需要：當月批准辦法及修訂、七項正式欄位映射、每週正式來源與截止口徑、適用資格及調店生效日、歷次入帳與去重紀錄、私有保存資料夾及執行者讀寫權限、允許下載的角色／範圍，以及既有週報任務可增加網站寫入與通知的明確授權。缺項只提供可核部分；這個流程不寫入 SPE 或金牌餘額。若尚無該資料夾權限或下載後端，須先處理該範圍，不能將 Excel 暫放 Pages。
