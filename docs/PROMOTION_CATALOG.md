# 手機價格與舊換新活動查詢

兩個既有查詢入口加入可收合的「當月購機優惠與舊換新加碼」與「使用已下載的參考報價 HTML」。兩者使用本頁記憶體，離頁清除，不新增後端、權限、雲端寫入、瀏覽器持久資料或公開促案資料檔。

## 活動查詢

載入 `promotion-catalog/v1` JSON，依機款、容量關鍵字、品牌、類型、通路及臺北查詢日期篩選。關閉、到期及未開始預設排除；資料範圍、版本、來源 SHA-256、原圖與原始條件可核對。預設最多顯示12筆，按「顯示更多活動」繼續。全通路適用列可通過任一通路篩選。

`discount` 是該活動折價上限；`stacked_cap` 是疊加後最高額，不能再加基礎折價。介面不計算成交價、不把舊機回收價當新機售價，也不自動判斷客戶資格。`null` 保留待核金額，明示 `0` 保留零。日期、來源、類型或金額不合格式時拒絕載入並清除舊活動，來源圖片只允許內嵌PNG／JPEG／WebP，文字一律跳脫。

活動資料有機密標記時只作本機／既有私有渠道交付，不提交到公開 Git 或 Pages。從某張圖列出的部分關閉款式不能反推所有未列款式；衝突名稱、容量、適用期與屬性名稱保留原文並註明。

## 參考價格 HTML

只擷取唯一 `<script type="application/json" id="DATA">` 的 JSON，不執行來源腳本、樣式、iframe 或網路。接收既有報價中心的欄位字典編碼，完整保留專案、資費、約期、零元、缺少單機價、來源商品與顏色差價。回收價逐原始顏色、回收商、S/A/B/C 保存；來源缺價不補零，未支援的回收商或衝突值拒絕載入。

本機來源標記為「參考檔來源日期」，隔離線上 active／previous 異動，不查詢或匯出正式異動。按重新整理回到原線上正式讀取；失敗的檔案不替換已有效載入的價格。活動JSON與價格HTML是兩個不同資料類型，不能互相替換。

## 完整回收查詢

參考HTML另由 `tradein-reference-core.js` 正規化完整回收資料，`tradein-reference-ui.js` 在本機來源載入後顯示完整工作區；原線上查詢資料與控制仍保留，回到線上來源或離頁時清除本機資料。兩家獨立選級：點子A/B/C、FDI S/A/B/C，Mac僅FDI A/B/C；各家同字母分級不代表同樣檢測結果。

商品分類、品牌、搜尋、型號與容量多選、價差／最高參考價排序與20筆分頁使用同一批資料。全部色款報價相同時可比較；色款差價、部分色款缺價、0值或缺價都不產出確定價差。0值保留原始數字以供核對，但顯示待確認，不能當零元收購；新機專案價明示0元的語意不變。可選取色款後比較及核對完整料號、來源列與原始名稱。Mac另顯示來源提供的標準／升級規格及A/B/C分級文字。

有效期逐機款依來源檔匹配，手機／平板與Mac不共用單一截止日；未知不推定，過期顯示歷史核對並寫入複製內容。複製包含分級、來源、有效期、核對日及不含促案／POS說明；剪貼簿不允許時提供可手動複製的文字。

回收入口僅使用原站三個固定HTTPS地址，使用者點擊後才開新分頁，`noopener noreferrer` 與 `no-referrer` 不帶入本頁或任何客戶／裝置資料。2026-11-05核對：點子App下載入口回401，須確認通路權限；FDI手機與筆電原入口都轉到同一FDI入口頁，不能聲稱已驗證手機／筆電檢測端到端。原QR已離線解碼，與點子文字入口相同。沒有自動下載／安裝App、登入回收商、送出序號或建立交易。

## 正式查詢與驗收版工作區

`query-workspace.js/css` 套用於正式查詢及本機驗收模式：手機價桌面使用左側篩選、右側比較表；手機保留搜尋與常用條件，其他條件可展開。活動及匯入來源放到價格工作區之後，導航仍可展開活動。資費／約期以 `1399(24)` 同列呈現，單方案卡片仍可切換。正式版保留原資料讀取、三家回收商及異動／版本功能；來源資料移入可展開區。正式 API 未提供的有效期、料號及 Mac 分級文字不從參考檔回填或推算。

完整參考回收工作區手機保留搜尋及分類，型號／容量／兩家分級／排序收在明確命名的展開區，所選報價與檢測入口排列在比較清單之前。分級、檢測、來源與 QR 說明集中在結果下方一個預設收合區；有效期、過期、待確認及錯誤狀態保留。這些完整欄位只使用當次載入的參考 HTML，不替換正式資料。沒有刪除價格條件、原始來源或功能。

先前私有驗收檔因瀏覽器拒絕 `file:` URL，只有原始碼與 DOM 驗證。正式 HTTPS 發布須另行核對實際頁面、桌機／窄螢幕畫面與正式資料版本；DOM 測試不能替代瀏覽器／實機視覺驗收。

## 私有驗收檔

可以在 repo 外生成內嵌資料的獨立HTML，沿用這兩個查詢頁與同一組程式。`data-price-mode="reference"` 停止開頁自動查線上價格。獨立檔須採 CSP 禁止 connect、frame、form、object 及外部腳本，只內嵌必要價格與機款資料，不帶入報價檔中的獎金或其他業務表。這種檔案是本機驗收交付，不等同正式資料庫同步或跨裝置更新。

## 檢查

- `node --test tests/promotion-catalog.test.cjs tests/quote-reference.test.cjs`。
- 設定 `QUOTE_REFERENCE` 為 repo 外授權來源檔可逐值驗證所有原始專案價與回收報價；不將真實來源複製進測試fixture。
- `playwright test tests/promotion-reference-ui.spec.js`；`PRIVATE_PREVIEW_DIR` 可測 repo 外生成的私有驗收檔，含窄屏、原圖、來源隔離及零外連檢查。
- 沿用 `tests/threec-query-ui.spec.js` 與 `tests/threec-phase1-ui.spec.js` 做既有流程回歸。所有正式API以合成資料攔截。
- `node --test tests/tradein-reference-core.test.cjs` 驗證完整回收語意；設 `QUOTE_REFERENCE` 可逐欄對帳來源的價格、料號、來源列、Mac規格與分級。
- 安裝於測試環境的 `jsdom` 可供 `tests/tradein-reference-dom.test.cjs` 使用；以 `NODE_PATH` 指向測試依賴、`PRIVATE_PREVIEW_DIR` 指向repo外驗收檔，驗證完整控制與無自動網路。這是DOM測試，不是瀏覽器截圖或實機驗收。
