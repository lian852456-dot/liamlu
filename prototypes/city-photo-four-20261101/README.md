前版與新版在相同鏡頭、光線和腳底基準並排，不用個別縮放製造差異。嘉玲左側是最初照片試作；李舒緩左側是共用城市原生角色模型。Q2 身體較短、四肢較圓，全身約 2.1 頭身，這是回應「不夠 Q」的新候選，並未取代共用城市已確認的比例。

## 使用

`node server.mjs` 後開啟 `http://127.0.0.1:4792/`。選人、拖曳旋轉，使用正面／45度／側面／背面、近看、行走／坐下／揮手、制服切換。

- `/?person=p3`：嘉玲。
- `/?person=p5`：李舒緩。
- 選人後可進入獨立城市試走，或選「城市光線近看」。`game.html?artReview=1&light=day|dusk|night` 使用原城市渲染器的固定光線供材質比較；預覽時間有明確標籤。近看控制本頁鏡頭，並暫隱會遮住人偶的路人與車輛；城市建物與原光線引擎保留。此模式不代表完整城市效能測量，普通遊戲路徑仍沿原操作與完整場景。

伺服器只開啟 `runtime/core/.private-v42-photo-four-q2/` 的合成試作角色；不讀原世界、真人員編登入、UID／錢包／購物／寵物／位置。原照片、員編與私有存檔不放在公開目錄或 Git。既有第一版保留於 Git `5aab9bf`、`avatar-portraits-v1.js` 及 `assets/portrait-hair-v1/`。

## 本輪證據

- `review-style.cjs`：兩人前／45度／側／背及新舊比較，行走、制服切換、坐姿裙襬座面間隙、390px無橫向溢出；20次切換回到相同角色後，GPU幾何50→50、貼圖11→11，髮型instance維持1。這是受測條件的有界資源證據，不是手機記憶體MB測量。
- `style-game-checks.cjs`：獨立城市行走／轉頭／拍照，無JS錯誤或context loss。
- `style-multiplayer.cjs`：兩合成客戶端互見兩款新外觀、前景按鍵位移傳至另一端。原先背景分頁按鍵未產生位移的測試timeout，已改為真實前景操作後驗證；未修改同步或碰撞引擎。
- `city-style-captures.cjs`：實際城市渲染器近看，固定720／1020／1260台北分鐘並核對，避免把WebSocket時間同步覆寫後的夜景誤標白天。
- `q2-models.test.cjs`：2項既有局部模型／裙裝關係檢查通過。
- `public-check.mjs`：公開靜態資產SHA讀回，私有來源／DB／原生建模檔不可直接下載。

最新收據與實際截圖在 `evidence/`。Blender髮型可編 `.blend`、GLB、建模腳本與匯入回讀收據在 `assets/portrait-hair/` 和 `tools/`。p3 5,592 tris；p5 7,544 tris；單一不透明PBR材質、無髮絲物理。
