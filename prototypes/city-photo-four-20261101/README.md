## 檢視與重製

使用Node 24執行 `node server.mjs`，開啟 `http://127.0.0.1:4788/`。頁面可選四位、拖曳旋轉、看正面／45度／側面／背面與頭部近看，並試站立／走路／坐下／揮手及三種光線。城市按鈕會進入相同造型的獨立城市；伺服器只開啟 `runtime/core/.private-v42-photo-four/`。

`tools/build_photo_four_hair.py` 及四份`.blend`保留可編輯來源。Blender 4.5.15 LTS匯出四份不透明髮型GLB，每份單mesh與單材質、共用512／256貼圖，無髮絲物理。`assets/portrait-hair/build-receipt.json`與`verification.json`記錄面數、尺寸與SHA；只有GLB被放入公開預覽，原照片和員編都不公開。

`start-preview-tunnel.mjs`使用既有已核准的免費通道工具；不建立排程、不修改固定小城入口。通道與Mac可用性不等於持久網站部署。

模型測試確認四份臉部頂點幾何不同，走路／坐下／揮手與換裝API可用，dispose釋放自有資源。真實Chromium檢查四位正側面與城市行走、轉頭、拍照；390px手機尺寸無橫向溢出，12次換角後保持1個髮型instance、3份共享髮型貼圖。這是Mac瀏覽器證據，不是iPhone Safari實機驗收。
