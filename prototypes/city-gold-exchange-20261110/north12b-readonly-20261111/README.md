`gold-read-contract.mjs`只接受有版本、有效日期及證據的confirmed對照表；待確認、過期、同員編或personKey有效日期重疊、店別暱稱不符會拒絕。先選本月最新完整已確認日結，再找本人；最新日結缺人不能退回舊日。保留負數及原原因，不加總每日balance、不把它當gross earned或可兌換額，不重扣備註已扣金牌。sourceHash包含整份選定日結與餘額，並非只hash標籤。
