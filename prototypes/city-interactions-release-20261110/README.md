# 共用城市：榮譽拳擊 V2 與 A 款寵物

版本 `20261110-city-play.1`。固定入口：https://lian852456-dot.github.io/liamlu/city-play.html 。沿用免費 Mac＋通道服務，並非獨立永久雲端主機。

## 使用方式

- 先在原小城登入。生活手帳 → **一分鐘拳台 · 榮譽對戰**。建立房間、把邀請碼給另一位已登入玩家，對方加入並接受後進行60秒對戰。J直拳／U勾拳／K防守／L閃躲／I後撤，手機可按畫面按鈕。結束或取消後按「回到進場位置」。
- 寵物店 → A 款小貓60遊戲金幣／A 款小狗75遊戲金幣。各四色同價，可先看3D預覽，再購買、選「跟隨」。毛色隨這筆所有權保存，目前不提供買後改色或舊款升級扣款。舊貓40／舊狗55與既有所有權不變。
- 正式金牌兌換規則為 **1面金牌 → 50枚遊戲金幣**，沒有反向兌換；目前仍關閉，未扣業績金牌。既有本地遊戲金牌錢包不冒充正式業績金牌，舊交易不重算。

## 接入及保存

拳擊同源沿用原 `GameStore.authenticate`、cookie、CSRF、UID與保存的外觀。支援現行完整人物adapter，不讓玩家指定別人的UID或造型。城市頁卸載後才載入拳台，避免兩個完整場景同時渲染。只開honor/0，sidecar不讀寫城市錢包；點回城取當下城市位置，不把擂台座標寫到城市。停權／撤銷／到期仍由原session驗證；心跳8秒在線、8–20秒重連中、超過20秒取消。

A款新增獨立商品ID，server驗毛色與固定價格，扣款／inventory／毛色metadata／ledger在同一交易；重送冪等、同款不可重買。跟隨與多人snapshot使用已保存所有權資料。新增毛色metadata，不遷移既有角色、錢包或表結構。原一次200金幣不重發。

## 正式金牌兌換的具體缺口

現行bootstrap的personalGold為trusted=false；沒有正式金牌金流連線。`runtime/employee/formal-contract.mjs`要求注入可信goldVerifier，但目前沒有可用實作／部署；正式匯入固定拒絕。仍缺以employeeId綁定的權威餘額與消費收據、本人正式驗證、原子扣帳或可重試的預留／確認／取消接口，以及兩端餘額readback。沒有這些接口，無法證明跨系統失敗退款、並發去重、每日刷新不補回已消費金牌。不得以每日snapshot覆寫餘額或以本地wallet.gold代替。此版只發布明確比率與disabled狀態，不代真人兌換。

## 回復

`deploy.mjs`先各自備份兩世界、保存舊程式，再只重啟backend，gateway與網址保留。切換前後比對持久表指紋與原200收據。回復只切回程式；絕不可將舊DB覆蓋正在遊玩的進度。拳擊可將私有設定boxingEnabled設false並重啟。上線後新增A款所有權要保留，若停賣應只隱藏商品／拒絕新購買，保留讀取與渲染，不能回退到不識別新商品的舊store後宣稱功能完整。

Git記錄排除所有.private目錄、DB、卡片和會話；QA server只在新的臨時資料夾建立合成角色。
